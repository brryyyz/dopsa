Задание 4. Техническое заключение

Основные проблемы компьютера — медленный HDD и недостаток оперативной памяти.

Рекомендуется установить 16 ГБ ОЗУ (2×8 ГБ DDR4) и SSD на 1 ТБ M.2 NVMe при поддержке материнской платы. Если поддержки нет, выбрать SATA SSD на 480 ГБ. HDD оставить для хранения файлов.

Дискретная видеокарта не требуется, встроенной Intel UHD Graphics 630 достаточно для школьных задач. Блок питания 400 Вт можно оставить, если он исправен.

Перед покупкой необходимо проверить совместимость памяти, наличие M.2 и поддержку NVMe. После модернизации компьютер будет быстрее загружаться и лучше работать с несколькими программами одновременно.

Задание 5. Проверка после модернизации

1. Проверить установку комплектующих и подключение питания.
2. В BIOS проверить обнаружение ОЗУ и SSD.
3. Запустить операционную систему и проверить загрузку.
4. Проверить состояние SSD и стабильность работы компьютера.
5. Записать итоговую конфигурацию и результаты проверки.
